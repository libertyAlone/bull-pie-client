# 牛派 · A 股量化分析与回测桌面客户端

**牛派**是一款运行在 Windows 上的 A 股研究工具：把「搜股票 → 看行情 → 加自选 → 写公式 → 跑回测 → 推到手机」这条链路收在一个本地客户端里。行情与财务数据来自你自行配置的同花顺金融数据服务开放接口，**缓存、指标计算与回测全部在你本机完成**。

## 运行环境

- Windows 10 1803+ / Windows 11（64 位）
- 依赖系统自带的 **WebView2 运行时**：Win11 与较新的 Win10 自带；若双击后闪退，到微软官网装一次
  [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Evergreen 版）即可
- 需要能访问你配置的数据接口地址（默认 `https://fuyao.aicubes.cn`）

## 五分钟上手

1. **安装 / 解压**后启动「牛派」。
2. 到 **设置 → API 凭据** 粘贴你的数据接口 Key 并点「保存并自检」。
   - 没有 Key？用同花顺账号登录 <https://fuyao.aicubes.cn/>，在「API Key 管理」页创建，复制备用。
   - Key 只保存在你本机的凭据库里，不会上传给软件作者；本软件不内置任何 Key。
3. 到 **设置 → 数据** 点一次「同步全市场代码表」——这样搜索才能离线命中中文名（几秒）。
4. 首页搜索框输入「茅台」或 `600519`，回车进入个股页看 K 线；或在自选页把常看的票加进来。
5. 想看策略表现：进 **回测** 页，选股票池与区间，用内置因子（均线交叉、动量、突破…）或自己写的通达信风格公式，点运行即可看到净值曲线、绩效指标与交易明细，可导出 CSV。

## 主要功能

- **行情**：指数概览、市场宽度（涨跌分布、板块概览）、板块涨跌榜、全市场排名、龙虎榜、连板天梯、市场情绪
- **自选**：分组管理、拖拽排序、批量快照、可调刷新档位（手动 / 5 / 10 / 30 / 60 秒，非交易时段自动停）
- **个股**：日 / 周 / 月 K 线，前复权 / 后复权 / 不复权，可配置均线、BOLL、神奇九转、成本线，副图可同时开多个（成交量 / MACD / KDJ / RSI / WR / CCI / OBV / BIAS / 自定义公式）
- **公式**：通达信风格表达式（含公式库管理、语法校验、未来函数禁用），一处编写、个股叠加 / 买卖点 / 选股 / 回测 / 监控多处复用；支持「按公式值排序取前 N」（例如今年以来区间振幅最大的前 50 只，可排除 ST、设最低价门槛）
- **回测**：事件驱动日线引擎，T+1、涨跌停与停牌处理、手续费与滑点建模、等权持仓，结果含净值曲线、绩效指标、交易明细，可复现、可导出
- **本地数据**：全市场 10 年日线底库按需导入（带进度），断网也能看缓存与跑回测；复权由本机按公司行动事件推导
- **AI 助手**（可选）：接入你自己的大模型（本机 Ollama 或订阅制接口），把自然语言翻译成公式 / 选股条件 / 复测复盘；**名单与数值一律由本地引擎计算**，模型只做翻译；支持提问时附带图片与文件
- **监控推送**（可选）：自定义指标规则 + 收盘 / 盘中巡检，命中后推到飞书群、企业微信群机器人或企业微信自建应用
- **命令行 / MCP**（进阶）：`bull-pie-cli.exe` 提供只读命令（状态、搜索、日线、选股、形态搜索、回测），加 `--json` 便于接脚本；`bull-pie-cli.exe mcp` 可把同一批只读能力暴露给支持 MCP 的 AI 客户端

## 数据放在哪、怎么迁移

- 数据目录：`%APPDATA%\com.bull-pie.app`（自选、回测记录、行情缓存、日志、下载的全市场底库都在这里）
- 想换到别的盘：在「设置 → 数据」里设置数据目录，或给软件进程设置环境变量 `BULL_PIE_DATA_DIR`
- 换机 / 重装：先在「设置 → 配置备份」导出配置（自选、界面偏好、监控规则、公式库），在新机器导入即可；行情缓存会按需重新拉取

## 常见问题

**双击后闪退 / 白屏？** 缺 WebView2 运行时，按上面「运行环境」装一次。

**提示没有凭据 / Key 无效？** 到「设置 → API 凭据」看「当前生效来源」；无效时回数据服务方控制台重新签发一个 Key。

**自选行情不刷新？** 非交易时段上游快照本身不变（界面会显示数据时间）；交易时段可把刷新档位调快些。

**提示「请求过于频繁」？** 数据服务方对调用频率有限制，软件会自动退避重试；持续失败时把刷新档位调稀一点。

**想推到手机上？** 个人微信没有官方推送接口，合规做法是用「企业微信自建应用」——在企业微信里创建应用，把 CorpID / Secret / AgentId 填到软件设置里，成员开启「微信插件」即可在微信里收到（设置页有分步说明）。

**杀毒软件报毒？** 安装包未做代码签名，部分杀软会对未知发布者告警；可核对下载页给出的 SHA256 后再决定是否放行。

**回测结果和别的软件对不上？** 先核对复权口径与费率：本软件回测默认**后复权、T+1、次日开盘成交**，与「收盘价买入」类工具的假设不同。
