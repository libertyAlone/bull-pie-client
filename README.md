<h1 align="center">牛派 · A 股行情研究与回测工具</h1>

**牛派**是一款在本机运行的 A 股行情研究工具：**Windows / macOS 桌面版**用来看行情、管理自选和持仓、查财务预警、做条件选股与策略回测，也可以看港美股（长桥只读行情，可选）；**Android 手机版**是桌面版的子集、只做 A 股，看行情 / 自选 / 快讯 / 持仓 / 提醒够用。apk下载链接：[夸克网盘](https://pan.quark.cn/s/8ae67bd9d267)

软件本身可免费使用，数据只保存在你自己的设备上。A 股行情需要你自己申请的数据接口 Key；港美股行情需要一个长桥开发者账号（软件里点一下授权即可）。软件不提供或代办任何数据账号。

> 第一次使用？可以先看带截图的 **[普通用户使用指南](USER-GUIDE.md)**。

## 使用要求

- **Windows 10（1803 及以上）或 Windows 11**，64 位系统；或者 **macOS**（Intel 与 Apple 芯片都支持）。
- 一个由你自己申请的行情数据 API Key。
- 想看港美股时，另需一个[长桥（Longbridge）开发者账号](https://open.longbridge.com/dashboard/tokens)：在「港美股」页点「用长桥账号登录」，浏览器里授权一次即可，**不用抄 App Key / Secret**（备选方案仍可用 API Key）。
- **Windows**：如果软件打开后白屏或闪退，请安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
- **macOS**：安装包没有做签名 / 公证，第一次打开会被 Gatekeeper 拦——在「应用程序」里**右键点牛派 → 打开 → 再点一次「打开」**即可（或执行 `xattr -dr com.apple.quarantine /Applications/bull-pie.app`）。
- **Android**：64 位 ARM 手机（`arm64-v8a`），系统 WebView 建议 Chrome 111 及以上（老机型能跑，但圆角、容器查询这类新样式会退化）。

## 三步上手

1. 安装或解压软件并启动。
2. 打开 **设置 → API 凭据**，填入自己的 API Key，然后点击保存和自检。
3. 打开 **设置 → 数据**，先同步全市场代码表，之后就可以搜索股票名称或代码开始使用。

如果还没有 API Key，可前往同花顺金融数据服务（Fuyao）申请。牛派不会内置、共享或代你申请 Key。

## 可以做什么

- **看市场**：查看大盘、涨跌分布、板块表现、资金情况和市场快讯。
- **看个股**：搜索股票（名称 / 代码 / **拼音首字母**，如 `gzmt` → 贵州茅台），查看 K 线、指标、财务摘要、公告等信息；「公告」每条可点**「AI 分析」**（配好模型才出现），先取正文再让模型说这条公告在说什么、偏利好还是偏利空。
- **管理自选**：把常看的股票加入自选并按分组整理（**新加入的排在列表最上面**）；也能**批量导入**（上传 CSV/TSV 或粘贴一列代码与名称，本地解析、本地匹配后再入库）。列表里每行名称下面带代码，右边跟一条**当日分时缩略走势**，点表头就能排序（**排好的方式会记住**）；电脑上还能勾选多只**批量移出**，或在「全市场排名」页勾选后**批量加入自选**。
- **查财务预警**：个股页「财务」tab 顶上按最近 5 年年报给一屏判断——32 条公开财报检查清单里**已判 27 条**，分「高风险 / 关注 / 通过 / 未判」四类，未判的会写明缺哪份数据（**没判不等于没问题**），每条都能点「问 AI」接着追。自选页和持仓页顶部有「**扫描预警**」，扫过的标的在名字前显示**高 / 中 / 低**角标；「公告」列表里命中立案调查、股东减持这类关键词的标题会挂红标。
- **记录持仓**：补录买卖、分红和出入金，查看当日概览、仓位占比、**持仓行业分布环图**、收益日历、清仓分析、交易笔记及股票盈亏排行；资产分析和收益日历还可以与上证指数做同期对比；配好模型后可用**「AI 分析持仓」**看权重、集中度、行业分布与逐只盈亏的客观解读（不给买卖建议）。
- **条件选股**：使用内置条件或自定义公式筛选股票（全市场扫描有进度条，可随时停止）。
- **策略回测**：用历史数据检查策略过去的表现，并查看收益曲线和交易明细（取数、寻优都有进度，可随时停止）。
- **复盘（研究计划 + 模拟盘）**：把看中的票记成「研究计划」（方向 + 理由，自动带上当时看到的形态与周期），之后用本地日线看记完之后 1 / 3 / 5 / 10 / 20 个交易日的表现，以及按依据分组的胜率与相对沪深 300 的超额；想练手就用**模拟盘**按参考价即时成交（**不接任何真实交易通道**）。
- **设置提醒**：满足价格、涨跌幅或公式条件时，发送到已配置的通知渠道。
- **查看更多市场**：查看全球指数、公募基金、期货和期权等信息。
- **看港美股（可选）**：接入长桥 OpenAPI，查看港股 / 美股的指数、自选、K 线与分时（美股还能单独看盘前 / 盘中 / 盘后 / 夜盘）、**个股资金流**、静态资料、**基本面（财报三表 / 主营构成 / 股东与高管 / 分红回购 / 一致预期与估值历史）**与**资讯（新闻 / 公告 / 机构评级；A+H 标的还显示 AH 溢价）**；页面顶部有**交易日历**（今天哪个市场开市、各自时段，自选刷新按它走），指数卡片下方挂着对应的**指数期货主连**，用来看盘前和夜盘的走向。**只读行情，不接交易通道、不下单。**
- **使用 AI 助手**：可选接入本地模型或自己的模型服务，用来解释结果和整理思路。
- **收盘 AI 总结（可选）**：自选页上的一行开关，交易日 16:00 后对自选生成一次总结并推送到已配置的通道，每天最多一次；正文由模型组织，数字全部来自本地算好的摘要，模型还会对当日公告标题做一次「重大利空」判定（同一标的当日只提醒一次）。不需要可以完全不开。
- **形态标注（可选）**：个股页「指标与公式」里的两个开关。**「形态标注」**按内置知识库在本机识别蜡烛图（乌云盖顶、红三兵这类）与经典图表形态（头肩、双顶底、三角、旗形、缺口…）：图上标短名、区间形态画框与突破位，图下**按类目分行**列出命中并给出依据数值，**跟着当前周期走**（日线看日线、周线看周线），港美股 K 线用的是同一套。**「量价信号」**是独立的第二个开关，把量能读法标在**成交量副图**上（《量价分析》6 条 + 《成交量分布》5 条，如吸筹区突破、趋势回踩、强拒绝），带关键价位的那几条还会在价格区画一条**同色横线**。判定全在本地完成，模型不参与。终端可用 `bull-pie-cli patterns <代码> --start <日期> --end <日期>` 验证同一份结果。
- **看筹码与成交分布（桌面端）**：K 线右侧那一栏按图上**当前可见区间**算筹码分布——获利比例、平均成本、90% / 70% 成本区间、集中度，还会标出最大筹码峰，点「AI 筹码解读」可以让模型讲一遍。图上另有一条按**真实成交额**算出来的**价值区色带与 POC 虚线**（《成交量分布》的口径）。两者算的是两件事、各画各的：筹码那一栏是从换手率反推成本（与东财同一个口径），价值区是成交额按价格摊开。
- **个股 AI 分析（可选）**：个股页右上角的**「AI 分析」**。软件先把这只票的价格位置、均线、RSI / MACD / KDJ、量能算好，再把**图上那些知识库形态的命中**（名字、前提、确认条件、依据数值）一起交给模型，让它讲清「现在的结构是什么、这些形态各意味着什么、后面可以观察什么信号」。**不预测涨跌、不给买卖建议**；分析用的周期与复权就是你当前图上的那一套，弹框里可以逐条核对它看到了什么。
- **技能与知识库**：AI 助手页的第二个 tab。按「技能包」分两层层级：一份知识 = 一个包，包里是一条条条目；多个条目的包收成一行，可整包启停、整体调顺序。软件自带**六个包、共 94 条**：**《日本蜡烛图技术》**（形态术语、判据与用法，32 条）、**《日本蜡烛图技术新解》**（差异指数 / 偏离指数、三线反向突破图、砖形图、钥匙图，4 条，只解释）、**《股市趋势技术分析》**（趋势线、支撑阻力、头肩、三角、矩形、旗形、缺口等西方经典图表分析，13 条）、**《量价分析》**（量能读法：放量止跌止涨、高峰、缩量测试、孤立支点、伪突破、动态趋势线，12 条）、**《蜡烛图精解》**（按根数分类的形态、酒田五法、形态可靠性评级，21 条）、**《成交量分布》**（成交最密价位、价值区、三个交易设置，12 条）——其中 **44 条**会在本地自动标注（形态与量价信号标在图上，价值区这类参考位直接画在图上）。你也可以把自己的 md 放进数据目录的 `skills/` 目录里，助手回答相关问题时会参考；软件只读这些文件、**不执行里面的任何脚本**。

部分功能需要先在 **设置 → 全市场日线数据** 中导入全市场日线。首次导入需要一点时间，之后通常只需更新新增数据。

## 数据与隐私

- API Key、模型 Key 和通知凭据只保存在你的设备本机，请不要发给别人，也不要贴到反馈截图里。
- 港美股用的是长桥的登录授权（OAuth），token 与 API Key 一样只保存在本机凭据库；港美股行情只在软件里展示，不参与 A 股的回测、选股与推送，也不会二次分发。
- 行情缓存、持仓记录、回测记录和软件设置默认保存在：Windows 是 `%APPDATA%\com.bull-pie.app`，macOS 是 `~/.local/share/com.bull-pie.app`（两个平台都一样：删掉这个目录等于清空本地数据，先备份再删）。手机版的数据存在应用自己的目录里，卸载应用就会一起清掉。
- 设置页的 **本地缓存** 能看到数据库文件、行情缓存与全市场日线数据占了多少，也可以只清掉**能重新拿回来的那部分**：清理行情缓存，或删除全市场日线数据。自选、分组、公式、监控规则、持仓账本、研究计划、模拟盘与 AI 历史都不在清理范围内。
- 设置页可以把**配置项**（界面偏好、监控规则、推送通道）与**数据项**（自选、公式库）分开导出 / 导入；电脑上还能把配置一键同步到手机（同一个 Wi-Fi，手机上出现 6 位配对码后确认）。
- 如果要完整保留持仓流水、历史回测和缓存数据，请备份整个数据目录。
- 使用外部 AI 服务时，界面会提示哪些内容将被发送；不需要 AI 功能可以完全不配置。
- **电脑版**会统计**匿名使用次数（PV / UV）**（手机版不统计），用来了解有多少人在用、哪些页面常用；
  不含任何业务数据（API Key、自选、持仓、公式、回测记录、发给 AI 的内容都不发）。不想参与可在
  **设置 → 高级选项 → 匿名使用统计**里关掉，关掉后一次请求都不发。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 双击后白屏或闪退（Windows） | 安装 WebView2 Runtime 后重试 |
| Mac 上打不开：提示「无法验证开发者 / 无法检查其是否包含恶意软件」，或 `.dmg` 挂载后应用起不来 | 安装包没做签名 / 公证，属于正常现象——按上面「使用要求」里的两步处理（右键打开，或 `xattr -dr com.apple.quarantine`）；另外确认下的是 `bull-pie_<版本>_universal.dmg`（一份同时支持 Intel 与 M 芯片） |
| 提示 API Key 无效 | 在设置页重新保存并自检，仍失败时到数据服务方后台重新申请 |
| 搜不到中文名称 | 到 **设置 → 数据** 同步一次全市场代码表 |
| 提示请求过于频繁 | 稍等片刻再试，并把自动刷新频率调低 |
| 磁盘占用想清一清 | **设置 → 本地缓存**里能看清数据库、行情缓存与全市场日线数据各占多少；「清理行情缓存」只删能重新联网取回来的行情，「删除全市场日线数据」会连那份 172 MB 的数据文件一起删（要用时再导入一次）。自选、公式、持仓这些不会被清 |
| 手机版怎么装、和电脑版差在哪 | 发布页下 `bull-pie-<版本>-android-arm64.apk`，传到手机点击安装（要允许「安装未知来源应用」）。手机版**只做 A 股**：行情 / 自选 / 快讯 / 持仓 / AI 助手在底部 tab，连板天梯、监控、复盘、设置收在「更多」里（**「更多」页顶部有搜索框**，输两个字就筛出要的功能）；港美股、全球指数、龙虎榜、选股 / 公式 / 回测、排名、基金、期货期权、命令行与 MCP 都留在电脑上。第一次用可以拿电脑上的「配置备份 → 同步到手机」把偏好、自选、公式和 Key 一起带过去 |
| 自选里有 ETF，但集合竞价没有显示 | 集合竞价数据只覆盖 A 股个股，ETF、指数等标的会自动跳过，不影响其他自选股票 |
| 港美股页提示「取不到」 | 指数本身只有盘中价（长桥对指数不返回盘前 / 盘后 / 夜盘），卡片第二行的指数期货主连来自第三方公开数据，网络或上游异常时可能暂时没有；个股的盘前 / 盘后 / 夜盘则取决于账号行情权限，以及该标的是否在夜盘可交易名单里 |
| 港美股行情与长桥 App 不一致 | 报价级别不同：免费档常见口径是港股 BMP（无实时推送、第 20 个之后延迟）+ 美股 LV1（含盘前盘后），卡片上会写明当前级别；买了行情卡才会变成实时，以长桥为准 |
| 安装包被系统提示风险（Windows SmartScreen） | 安装包暂未做代码签名，请只从上面的正式发布页下载；macOS 的对应提示见上一行 |
| 回测结果与其他软件不同 | 不同软件的复权方式、交易价格和手续费假设可能不同，请先核对回测设置 |
| 持仓总资产显示为负数 | 如果只记录了买入、没有先记录入金，现金会变成负数。请在第一笔买入之前补录入金；只想从今天起跟踪的话，记「买入」时勾上「按当前持仓补录」（数量填现在持有多少股、价格填持仓成本价，会自动配一笔等额入金） |
