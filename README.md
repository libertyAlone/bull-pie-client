<h1 align="center">牛派 · A 股量化分析与回测桌面客户端</h1>

**牛派**是一款运行在 Windows 上的行情研究工具：把「搜股票 → 看行情 → 加自选 → 写公式 → 跑回测 → 推到手机」这条链路收在一个本地客户端里，另含 7×24 快讯、全球指数、期货期权与公募基金。软件**支持接入同花顺金融数据服务（Fuyao）开放接口**——凭据由你自己申请并在本机填写；**缓存、指标计算与回测全部在你的机器上完成**，软件本身不提供数据、也不代你注册。

> 第一次使用建议先看 **[普通用户使用指南](USER-GUIDE.md)**：用截图快速了解各个页面，以及从配置数据到看行情、回测和推送的完整流程。

> 本仓库只存放**发行包**（安装版与免安装版），源码不公开。GitHub 在本页自动生成的
> `Source code (zip/tar.gz)` 只是本仓库自身的快照，不是本项目源码。

## 运行环境

- Windows 10 1803+ / Windows 11（64 位）
- 依赖系统自带的 **WebView2 运行时**：Win11 与较新的 Win10 自带；若双击后闪退，到微软官网装一次
  [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Evergreen 版）即可
- 需要能访问你配置的数据接口地址（默认 `https://fuyao.aicubes.cn`）；「快讯」与「全球指数」两块
  数据来自东方财富的公开接口，被网络限制时只有这两块会留空，其余功能不受影响

## 五分钟上手

1. **安装 / 解压**后启动「牛派」。
2. 到 **设置 → API 凭据** 粘贴**你自己的**数据接口凭据并点「保存并自检」。
   - 还没有凭据？用同花顺账号登录 <https://fuyao.aicubes.cn/>，在「API Key 管理」页创建，复制备用（是否可商用请以该服务的条款为准）。
   - Key 只保存在你本机的凭据库里，不会上传给软件作者；本软件不内置任何 Key。
3. 到 **设置 → 数据** 点一次「同步全市场代码表」——这样搜索才能离线命中中文名（几秒）。
4. 首页搜索框输入「茅台」或 `600519`，回车进入个股页看 K 线；或在自选页把常看的票加进来。
5. 想看策略表现：进 **回测** 页，选股票池与区间，用内置因子（均线交叉、动量、突破…）或自己写的通达信风格公式，点运行即可看到净值曲线、绩效指标与交易明细，可导出 CSV。
6. 想跑全市场：到 **设置 → 数据** 点一次「导入全市场日线」（约 172 MB，首次几分钟），之后**选股**与**回测**就能覆盖全市场；
   代码表与日线每天会自动补增量，不用重复手动导入。
7. 会用命令行、或想让自己的 AI 直接查这些数据？看 [进阶用法](#进阶用法)：命令行一份、MCP 一份。

## 主要功能

- **行情总览**：六个指数与北交所概览、市场宽度（成交额、涨跌分布、四个榜单）、市场情绪（涨停 / 跌停 / 炸板 / 连板梯队 / 热股榜）、板块涨跌榜与板块日线、全市场排名、龙虎榜（机构 / 游资 + 席位）、连板天梯、**集合竞价**（默认收起成一行，**09:15–09:30 自动展开并每 30 秒刷新**：短线风向标基准 + 自选竞价快照，含竞价量比、相对昨日量、未匹配量）
- **快讯**：单独一个 tab，最新在最上、按日期分组（今天 / 昨天 / 年月日），上游标为重点的条目加红，盘中 30 秒 / 其余时间 5 分钟轮询；内容来自东方财富公开接口，只做本地展示
- **全球指数**：单独一个 tab，最多盯 24 个国际指数（默认 9 个：道指 / 纳指100 / 标普500 / 恒指 / 日经225 / 韩国KOSPI / 台湾加权 / DAX / 富时100），配一张**世界地图**按城市标注涨跌幅 + 涨跌排序清单 + 分市场小结；轮询按「被盯市场是否开着」自动切 60 秒 / 5 分钟
- **自选**：分组管理（右键加入分组）、拖拽排序、批量快照、可调刷新档位（手动 / 5 / 10 / 30 / 60 秒，非交易时段自动停）
- **个股**：日 / 周 / 月 K 线，前复权 / 后复权 / 不复权，可配置均线（预设 + 自定义 30 / 120 / 250 等）、BOLL、神奇九转、成本线，副图可同时开多个并共享时间轴（成交量 / MACD / KDJ / RSI / WR / CCI / OBV / BIAS / 自定义公式）；另含 **F10**（财务三表与五类指标、分红送配、人气与异动）与**外部数据**（主力资金流、股东户数、公告，均标注来源）
- **公式**：通达信风格表达式（含公式库管理、语法校验、未来函数禁用），一处编写、个股叠加 / 买卖点 / 选股 / 回测 / 监控多处复用；支持「按公式值排序取前 N」（例如今年以来区间振幅最大的前 50 只，可排除 ST、设最低价门槛）
- **信号体检**：以公式命中为事件，统计命中后 1 / 3 / 5 / 10 / 20 个交易日的收益、超额、上涨占比、t 值与分年度稳定性——用来判断一条公式到底值不值得用
- **期货与期权**：独立 tab。期货品种目录（交易所 / 夜盘 / 保证金 / 基差 / 行情代码）+ 日线、主连基差与各现货口径、品种日持仓、历史仓单；期权品种目录 + 按完整合约代码查资料与日线
- **公募基金**：独立 tab。概况 / 业绩 / 场内行情 / 持仓 / 财务与资讯；ETF 有行情与 K 线，LOF 与场外基金只有净值（上游限制，界面会写明）
- **回测**：事件驱动日线引擎，T+1、涨跌停与停牌处理、手续费与滑点建模、等权持仓，股票池支持自选 / 手工列表 / 全市场底库，结果含净值曲线、绩效指标、交易明细，可复现、可导出
- **本地数据**：全市场 10 年日线底库按需导入（带实时进度），收盘后自动同步增量，断网也能看缓存与跑回测；复权由本机按公司行动事件推导（不采信上游预计算的复权价）
- **AI 助手**（可选）：接入你自己的大模型（本机 Ollama 或订阅制接口）。直接问数据也行——「600519 现在多少钱」「帮我看看它的市盈率」「今天涨停梯队什么样」，助手会**自己调用本地工具**去取（行情 / K 线 / 财务 / 估值 / 选股 / 相似形态 / 市场情绪 / 集合竞价 / 期货），回答下方列出**依据**：用了哪个工具、什么参数、结果多少字，数字可以逐个核对；也能把自然语言翻译成公式 / 选股条件 / 复盘分析，还能「照着某只票的形状再找几只」。**名单与数值一律由本地计算**，模型只负责挑工具与复述；模型不支持工具调用时会自动切回原来的「翻译意图」模式，不会报错
- **监控推送**（可选）：自定义指标规则 + 收盘 / 盘中巡检，命中后推到飞书群、企业微信群机器人或企业微信自建应用
- **命令行 / MCP**（进阶）：`bull-pie-cli.exe` 提供只读命令（状态、搜索、日线、选股、形态搜索、回测、行情快照、指数与板块、市场概览、集合竞价、期货期权），加 `--json` 便于接脚本、`--out` 直接落 UTF-8 文件；`bull-pie-cli.exe mcp` 把 **44 个只读工具**（行情、市场、财务、公式买卖点、期货期权、基金）暴露给 Claude / Cursor 等支持 MCP 的客户端。详细用法见 **[cli-intro.md](cli-intro.md)**（脚本化场景、逐条命令与退出码）与 **[mcp-intro.md](mcp-intro.md)**（接入 Claude / Cursor、44 个工具清单、怎么问才准）
- **配置备份**：导出 / 导入自选、界面偏好、监控规则、公式库与推送通道；导入整体替换并给出明细回执

## 数据放在哪、怎么迁移

- 数据目录：`%APPDATA%\com.bull-pie.app`（自选、回测记录、行情缓存、日志、下载的全市场底库都在这里）
- 想换到别的盘：在「设置 → 数据」里设置数据目录，或给软件进程设置环境变量 `BULL_PIE_DATA_DIR`
- 换机 / 重装：先在「设置 → 配置备份」导出配置（自选、界面偏好、监控规则、公式库），在新机器导入即可；行情缓存会按需重新拉取

## 常见问题

**双击后闪退 / 白屏？** 缺 WebView2 运行时，按上面「运行环境」装一次。

**提示没有凭据 / Key 无效？** 到「设置 → API 凭据」看「当前生效来源」；无效时回数据服务方控制台重新签发一个 Key。

**自选行情不刷新？** 非交易时段上游快照本身不变（界面会显示数据时间）；交易时段可把刷新档位调快些。

**首页「集合竞价」怎么是收起来的？** 这块默认只占一行，**开盘竞价时段（09:15–09:30）会自动展开**并每 30 秒刷新，过了这个时间又收回——竞价数据在 09:30 之后就是终态，一直开着只是白占接口配额。想随时看就点一下「▸ 展开」，之后会按你的选择、不再自动切换。

**期货里「主力合约」和「主连」有什么区别？** 主力合约是当下持仓 / 成交最大的那个月份合约（会换月）；主连是把主力合约按月接起来得到的连续行情（代码形如 `CUZL.SHF`）。数据服务方只对中金所品种给出主力合约代码，所以商品期货默认看的是主连。

**「快讯」和「全球指数」是谁的数据？** 这两块来自东方财富的公开接口（行情与财务来自同花顺数据服务）。接口未文档化、随时可能调整，所以软件对它们**只做展示**，失败时会提示并退回落上一次的结果，也不把它们用于选股、回测或推送。

**提示「请求过于频繁」？** 数据服务方对调用频率有限制，软件会自动退避重试；持续失败时把刷新档位调稀一点。

**想推到手机上？** 个人微信没有官方推送接口，合规做法是用「企业微信自建应用」——在企业微信里创建应用，把 CorpID / Secret / AgentId 填到软件设置里，成员开启「微信插件」即可在微信里收到（设置页有分步说明）。

**杀毒软件报毒？** 安装包未做代码签名，部分杀软会对未知发布者告警；可核对下载页给出的 SHA256 后再决定是否放行。

**回测结果和别的软件对不上？** 先核对复权口径与费率：本软件回测默认**后复权、T+1、次日开盘成交**，与「收盘价买入」类工具的假设不同。
